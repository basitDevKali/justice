Justice Module

Two contexts, Court and Prison. A verdict in the Court creates the imprisonment in the Prison. Both contexts connect to the citizens and finances of Hannes's modules and to Jobs and Complaint Management in Julia's Operations & Safety module.

Validations

onValidation on HEARINGDATE, J_COURTCASE

  • HEARINGDATE must not be before FILINGDATE.
  • One JUDGE holds at most 3 hearings on the same calendar day. Cases with STATUS = DISMISSED do not count.
  • Message: "Judge {NAME} already has 3 hearings on {DATE}. Please choose a different day or judge."

onValidation on CITIZEN_ID, J_INMATE

  • A citizen can have only one J_INMATE row with STATUS = IN_CUSTODY at a time.
  • Message: "{CITIZEN} is already in custody (inmate number {NUMBER})."

onValidation on CELL, J_INMATE

  • At most 2 inmates with STATUS = IN_CUSTODY per CELL.
  • Inmates with SECURITYLEVEL = HIGH get a cell of their own.
  • Message: "Cell {CELL} is full. Please choose a different cell."

Actions

ScheduleHearing_action

On J_COURTCASE
  • Allowed while STATUS = FILED or HEARING_SCHEDULED (rescheduling)
  • Dialog asks for date and time, writes HEARINGDATE (validation above applies)
  • Sets STATUS = HEARING_SCHEDULED

PronounceVerdict_action links Gericht → Gefängnis + Finanzen

On J_COURTCASE
  • Checks STATUS = HEARING_SCHEDULED and HEARINGDATE ≤ now, otherwise error "The hearing has not taken place yet"
  • Dialog: VERDICT, plus FINEAMOUNT (for FINE) or SENTENCEMONTHS (for PRISON)
  • FINE: calls the Finanzen service to create a receivable for the citizen and stores its id in RECEIVABLE_ID
  • PRISON: inserts a J_INMATE row (case, citizen, ADMISSIONDATE = today, PLANNEDRELEASEDATE = today + months) and opens its EditView for CELL and SECURITYLEVEL
  • Sets STATUS = VERDICT

AssignJob_action links Gefängnis → Jobs

On J_INMATE
  • Allowed only for STATUS = IN_CUSTODY and SECURITYLEVEL ≠ HIGH
  • Lookup shows only open jobs of the Jobs module
  • Writes the selected job to JOB_ID

ReleaseInmate_action

On J_INMATE
  • Writes today's date to RELEASEDATE
  • Before PLANNEDRELEASEDATE: STATUS = ON_PAROLE, otherwise STATUS = RELEASED
  • Frees the cell. If no imprisonment of the case is IN_CUSTODY any more, the case gets STATUS = CLOSED

Calculated Display Values

remainingDays (No database column needed!)

On J_INMATE, read-only, shown while STATUS = IN_CUSTODY
SELECT GREATEST(DATEDIFF(PLANNEDRELEASEDATE, CURRENT_DATE), 0)
FROM   J_INMATE
WHERE  J_INMATEID = :currentInmate

Example: admission 01/09/2026, 6 months → planned release 01/03/2027. On 12/10/2026 the view shows 140 days.

priorConvictions (No database column needed!)

On J_COURTCASE, read-only, helps the judge before the verdict

APIs

J_CriminalRecord_rest offered

GET ?citizenId=…

Returns prior convictions and whether the citizen is in custody.

{ "inCustody": false,
  "convictions": [
    { "case": "J-2026-0004",
      "verdict": "PROBATION",
      "date": "2026-04-17" } ] }

Used by Jobs (background check of applicants) and Bürger (certificate of good conduct).

J_CourtCase_rest offered

POST · create case

Complaint Management escalates a complaint to court. Body: COMPLAINT_ID, CITIZEN_ID, TITLE. The case starts with CASETYPE = ADMINISTRATIVE and STATUS = FILED, and the response returns the CASENUMBER.

Finanzen · createReceivable needed from Hannes

Service or REST, called by PronounceVerdict_action

Input: CITIZEN_ID, amount, reason ("Fine J-2026-0012"). Output: id of the receivable, stored in RECEIVABLE_ID.
